# 默写卡自测 · MATH2003 数学分析

把「定理 / 定义默写卡」生成为一个**自测网页**：抽一张卡 → 默写 → 对照答案 → 可选 AI 判定 → 标记 ✓/✗，之后可只抽错题再来一轮。

## 使用

- **电脑**：双击 `index.html`
- **手机 / 分享**：用 `17-默写卡-Ch1-4-单文件.html`（KaTeX 与字体全部内联，约 680KB，双击即用、不依赖网络）

## 功能

- 打乱抽卡 / 只抽 ✗ 的 / 进度统计（存浏览器 localStorage，换设备不同步）
- **默写框支持 LaTeX**：直接手敲 `$...$`，下方实时渲染预览；写了 LaTeX 但没加 `$` 时会提示
- **LaTeX 编辑框**（折叠面板）：18 个常用按钮（分式 / 根号 / 上下标 / lim / ∑ / ∀ / ∃ / ∈ / ≤ / ≥ / ≠ / → / ⇒ / ε / δ / ∞ / |）+ 实时预览；先在编辑框里选中一段再点按钮可自动包裹；拼好一键插入默写框（自动补 `$…$`、防止与相邻 `$` 粘成 `$$`）
- **AI 判定（可选）**：填入 DeepSeek API key（只存本机浏览器 localStorage，不会写进 html）后可一键判定；也支持手写拍照判定；或走「复制给 AI」手动路径
- 键盘：空格 / 回车 = 显示答案，1 / 2 / 3 = 过了 / 没过 / 跳过

## 重新生成

改卡片源 `17-默写卡-Ch1-4.md` 后：

```bash
python _build_默写卡自测.py 17-默写卡-Ch1-4.md . --single
```

输出 `index.html`（本地版，需同目录 `katex/`）与 `17-默写卡-Ch1-4-单文件.html`（全内联）。

脚本首次运行会从 `D:\MarkdownViewer\lib\katex` 复制 KaTeX（路径可在脚本顶部修改）。

## 卡片源格式

```
## 卡 N

题目文本

---
答案文本（支持 $...$、$$...$$、\(...\)、\[...\]）
```
